# MIRU2026 若手プログラム — ベンチマーク論文をベンチマークする

MIRU2026若手プログラム「わかりやすい、読みやすいを深掘る」のベンチマークグループによるWebサイトです。調査から得たベンチマーク論文の読みやすさに関する指針と、サーベイ対象の論文一覧を公開します。

## ページ仕様

サイトはビルド工程を必要としない、GitHub Pages向けの静的な単一ページです。

### コンテンツ構成

1. プロジェクト概要
2. ベンチマークを提案する4つのモチベーション
   - 領域開拓型
   - 欠落補完型
   - 更新・難化型
   - 評価再設計型
3. わかりやすいベンチマーク論文を構成する8つの観点
4. 調査論文リスト
5. 追加実験：論文のセクション画像を用いたVLM評価
6. プロジェクトメンバーと発表ポスター

### VLM評価実験

論文リストの後に追加コンテンツとして、Introduction、Method、Experimentsなどをセクションごとにキャプチャした画像をVLMへ入力し、初見の読者にとってのわかりやすさを評価した実験を掲載します。

- GPT-5.5を使用し、各セクションの画像一式を個別に評価した実験条件を表示
- 実際に使用した評価プロンプトを常時表示し、クリップボードへのコピーボタンを提供
- BLINK、JMMU、Paper2Posterのセクション別評価例を、初期状態では要約表示
- 選択した出力例を3列ブロック下の共通詳細パネルへ表示
- 評価理由をデスクトップでは2列、モバイルでは1列で表示
- 画像解像度や使用モデルなどに評価が依存することを示す注意書き

### 論文リスト

論文データは `static/js/papers.js` から読み込みます。現在の主な機能は以下のとおりです。

- タイトル・著者・掲載先・分野・モチベーションタグ・日本語要約・コメントを対象としたキーワード検索
- 分野とモチベーションタグによる絞り込み
- 各論文のモチベーション分類を色付きラベルで表示
- 新しい順（デフォルト）、古い順、タイトル順での並び替え
- Abstractに基づく日本語要約と「わかりやすさ」コメントの展開表示
- 外部論文ページへのリンク
- 16件単位の追加表示
- `Command/Ctrl + K` による検索欄へのフォーカス

### デザイン

## 論文データの更新

`static/data/サーベイ論文（ベンチマークグループ）.xlsx` の「サーベイ論文リスト」シートを編集後、次のコマンドをリポジトリルートで実行します。

```bash
python3 scripts/extract_papers.py \
  'static/data/サーベイ論文（ベンチマークグループ）.xlsx' \
  static/js/papers.js
```

抽出スクリプトはPython標準ライブラリのみを使用します。Excelの列は次のように変換されます。

| Excel列 | 出力フィールド | 用途 |
| --- | --- | --- |
| A | `url` | DOIまたは論文URL |
| D | `title` | 論文名 |
| E | `authors` | 著者 |
| F | `venue` | 掲載ジャーナル・学会 |
| G | `year` | 掲載年月日 |
| H | `field` | 分野・ジャンル |
| I | `motivation` | モチベーション分類 |
| J | `clarity` | わかりやすさに関するコメント |

`static/data/abstracts_ja.json` には、論文名をキーとして各論文のAbstractに基づく日本語要約を保存します。抽出時にExcelの論文名と照合し、`abstractJa` として `papers.js` へ自動結合します。要約の不足や、Excelに存在しない古い要約がある場合は抽出時に警告されます。

論文URLから確認用の原文Abstractを取得する場合は、次のコマンドを実行します。取得結果はそのまま公開せず、内容と取得元を確認してから `abstracts_ja.json` の日本語要約を更新してください。

```bash
python3 scripts/fetch_abstracts.py static/js/papers.js /tmp/abstracts_raw.json
```

生成された `static/js/papers.js` もGitへ追加してください。内容は自動生成されるため、原則として直接編集しません。

## ローカル確認

相対リンクを本番と同じ条件で確認する場合は、リポジトリルートでローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## 公開時の確認事項

- `static/data/` のPDFとExcelがGitに追加されていること
- Excel更新後に `static/js/papers.js` を再生成していること
- 新規論文に対応する日本語要約が `static/data/abstracts_ja.json` にあること
- ポスターリンクと各論文の外部リンクが開けること
- デスクトップとモバイルの両方で表示を確認すること
